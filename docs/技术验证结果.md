## 1. 当前结论

Go＋MyGo 已在当前 macOS／arm64 上完成真实构建和启动。自有 Fixture B 可被收起，收起期间两个夹具后台计数继续增长，随后恢复显示，已观察的改动可释放。两种独立 UI 已建立并共享同一会话，基础操作和单窗口截图已取得证据。

**全面通知保护仍没有被证明的公开实现路径。** 用户实际触发测试通知，返回 `mygo: the user does not allow notifications`；这证明该次请求返回此错误，不证明用户曾拒绝授权，也不证明成功发送、横幅／声音表现或跨应用屏蔽。当时尚无完整应用开发授权，后已由新指令覆盖；通知能力仍不能承诺。

用户曾两次报告范围外选择未出现，历史失败保留。随后由代理独立执行真实 NSWorkspace 激活、AppKit 可见状态采样、截图和原生按钮点击：面板可见，并完成返回／加入本次／退出三条路径。发现并修正了两处独立缺陷：共享 busy 状态变化未刷新选择面板，导致按钮保持禁用；非激活面板的返回动作缺少前台交接，导致 A 激活被拒绝。原始用户 Dock 不可见的具体环境条件未原样复现，不能把这两处修正冒称为其全部根因。

重启自有宿主后的已登记改动恢复也已实测。所有实验进程已正常退出，改动记录已释放。当前可自行执行的验证由代理完成，不再要求用户逐项协助。

## 5. 探针修正与未解决问题

1. macOS `/var`／`/private/var` 合法父目录别名被误拒绝：先规范化可信根，再拒绝运行子目录符号链接，保留负向测试。
2. 直接运行 bundle 内程序无法取得启动身份：改用 Launch Services，校验真实应用 PID，不能拿 open 启动器 PID 冒充。
3. 隐藏返回未确认就立即清理：观察真实延迟结果，工程超时后保留 unknown，不把“当前可见”当作 pending 已清理；有回归测试先复现旧机制再修正。
4. 截图枚举混入辅助／旧窗口：改用明确 MyGo 窗口句柄，CoreGraphics 只查询指定编号的所属进程；截图已实际成功。
5. WebView 计时仅操作后更新：补充快照刷新，不对计时使用每秒 aria-live 播报；两个界面统一按整秒显示。
6. 选择面板的共享状态刷新遗漏：操作完成后主窗更新而面板保持 busy=true 的旧渲染，截图／AX 可复现三个按钮禁用。改为刷新全部现存视图，已实测按钮可点。返回动作另补宿主获得前台后再交接到 A，并观察成功；不在检测范围外时自动抢前台。ShowInactive 假设经过三次前后对比被否定，没有加入显示逻辑。
7. 证据检查接受未知状态字符串：增加固定枚举、人工项目和来源校验；回归测试证明未知判定必须被拒绝。
