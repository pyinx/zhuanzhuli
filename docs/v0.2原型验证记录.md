## 1. 为什么仍缺真实画面和操作证据

此前自动浏览器对本地 file 协议读取给出明确安全拒绝，只允许 HTTP／HTTPS，并禁止以其他浏览器、协议转换或间接执行取得同一结果。当前页已由用户打开不等于该限制被解除。本轮未重试或绕过，也未通过执行页面的替代环境伪装浏览器验证。

因此，本记录区分源码能确认的原因与仍需实际操作的结果。已请用户对开始、暂停、退出和连续删除撤销提供手动操作观察；尚未收到的观察不计为通过。

## 2. 本轮发现与修复

| 编号 | 问题与触发 | 原因 | 已修正的源码 | 仍需真实检查 |
| --- | --- | --- | --- | --- |
| PV01 | 开始后，键盘可能留在已移除的开始按钮；Tab／Esc 路径不清楚 | 入场没有接收焦点，背景菜单仍可操作，键盘范围只包含提示和控制面板 | 入场声明为临时对话层；开始时定位“跳过”，背景暂不可操作，Tab 留在入场层；Esc 取消进入，跳过后返回菜单入口 | 中文输入结束后开始、Tab／Shift-Tab、Enter 跳过、Esc 取消与减少动态效果组合 |
| PV02 | 选择“本次允许微信”后失去可继续操作的键盘焦点 | 提示按钮被重绘移除，没有指定后继焦点 | 允许本次后把焦点交回菜单栏入口；本次应用集合与默认组合仍分开 | 加入后可查看本次应用，退出后默认组合不被改写 |
| PV03 | 有目标但没有应用时，错误出现却未定位相关入口 | 开始校验只重绘错误文字 | 错误与“更改…”关联，并定位该入口，提供一次状态说明 | 键盘选择应用后返回继续；VoiceOver 仍待实测 |
| PV04 | 超时提示出现后立即退出、再开始，下一次可能仍显示“预设时间到” | 短暂提示时间独立保存，开始／退出没有清理 | 新会话创建及退出均清除旧提示时间；下一次仍按新会话计时 | 超时提示期间退出，关闭视觉快速开始；新会话不能出现旧提示 |
| PV05 | 较矮窗口可能出现整页滚动，菜单栏离开可视区；控制面板高度只按浏览器估算 | 桌面最小高度固定为 860／840 像素；控制面板没有扣除实际评审工具条与入口占用 | 画布按可用视口布局；开始／设置／历史内部滚动，标题栏保留；开始操作栏保留；控制面板按实际剩余高度限高；提示与入场内容可滚动 | 各尺寸、浏览器文字大小、缩放、长目标、打开辅助偏好后的定位和遮挡截图 |
| PV06 | 恢复提示展示的目标与查看暂停会话后的目标可能不同 | 提示直接使用固定示例目标，会话目标则沿用当前输入 | 两处统一读取恢复会话的同一目标，按文本转义展示 | 先写不同目标或查看长目标，再进入异常恢复状态，对照提示和暂停面板 |
| PV07 | 入场白字在雪地、沙滩等浅色画面上可读性不稳定 | 只有轻暗层和文字阴影，未为小字建立可控底色 | 入场标题／引导与媒体身份说明采用已有的受控实底文字配色；保留静态场景，不整体大幅压暗画面 | 四主题、浅深色、静态引导、大字；检查文字、人物、跳过入口与说明之间的实际间距 |

这些处置是源码层修正，不是已执行的鼠标、键盘、视觉或辅助技术测试。

## 3. 交互验证矩阵

下表是可逐项操作的检查路径。当前每项都只有源码核对，浏览器结果均为待测；不能将预期填成实际结果。

| 路径 | 操作与边界 | 预期 | 当前证据 |
| --- | --- | --- | --- |
| 正常开始 | 输入目标，选 15／30／60，开始，跳过入场 | 只创建一次本页会话；工作回到原生应用说明图，菜单栏可控制 | 源码核对；浏览器待测 |
| 目标为空 | 空白或仅空格开始 | 保留其他配置，定位目标框，不创建会话 | 源码核对；浏览器待测 |
| 自定义边界 | 输入 0、181、小数、字母；再输入 1、180 | 非法值就地说明；合法整数可选用，候选范围身份明确 | 源码核对；浏览器待测 |
| 无应用 | 清空默认组合，填目标后开始 | 定位“更改…”；进入应用选择，不丢目标和时长 | PV03；浏览器待测 |
| 入场中断 | 人声开／关，Tab、Enter 跳过或 Esc 取消 | 不误操作背景；取消保留准备内容；未开始有效计时不留投入记录 | PV01；浏览器待测 |
| 工作控制 | 菜单栏打开，外部点击、Esc；再开设置／历史 | 锚点对应，收起不结束专注，不堆叠控制面板 | v0.2 已有修订；浏览器待测 |
| 暂停与恢复 | 工作中暂停，等待，再继续 | 同一目标与会话，暂停间隔不计入有效时间 | 源码核对；浏览器待测 |
| 保护未验证／受限 | 取消、配置、手动演示结果或明确部分继续 | 不经固定等待自动就绪；取消保留输入；部分保护身份清楚 | 源码核对；浏览器待测 |
| 范围外应用 | 分别返回、允许本次、退出 | 三个结果明确；只改本次范围；后继键盘入口可达 | PV02；浏览器待测 |
| 超时与新会话 | 到点继续；提示期间退出并快速重开 | 只提示一次；保护与计时继续；新会话无旧提示 | PV04；浏览器待测 |
| 退出与记录 | 提前／超时／暂停后退出，主动打开历史 | 静默记录，不弹总结；状态不推断目标完成 | 源码核对；浏览器待测 |
| 连续删除撤销 | 连删两条，逐次撤销；期间加入一条新记录 | 恢复原记录顺序，新记录位置正确，焦点可继续操作 | v0.2 已有修订；浏览器待测 |
| 异常恢复 | 先使用不同目标，再切到恢复，查看暂停会话 | 提示与会话目标一致；不补算未运行时间，不自动继续 | PV06；浏览器待测 |
| 媒体失败与双屏 | 失败状态重试／继续；切换双屏说明 | 有恢复路径；双屏只作布局说明，不声称控制实际屏幕 | 源码核对；浏览器待测 |

## 4. 视觉验证矩阵

| 组合 | 重点检查 | 当前证据 |
| --- | --- | --- |
| 1280×800 与 1024×640，正常字号 | 开始按钮、标题栏与菜单入口始终可达；内部滚动不遮挡控件 | 源码限高和滚动规则；截图待补 |
| 800×600，长目标与自定义输入 | 表单、窗口和确认提示不超出画布；错误文案与操作可见 | 源码换行和边界规则；截图待补 |
| 较大文字／150% 与 200% 缩放 | 评审工具条与窗口不互相挤出；计时面板内部可滚动 | 相对 token 与可用高度规则；实际缩放待测 |
| 四主题入场与静态引导 | 受控文字底色、人物、跳过和媒体说明层级清楚 | 实底配色与源码；最终合成画面待补 |
| 浅色、深色 | 主窗口、工作说明、设置、历史与错误提示语义一致 | 静态配色检查；真实强调色、材质与显示待测 |
| 三项辅助偏好分别及组合开启 | 静态反馈、实底回退、边界与焦点不丢失 | 源码分支；系统与浏览器支持待测 |

尺寸为浏览器原型的人工验证条件，不是产品已锁定的最小原生窗口尺寸。原生窗口、菜单、输入法、VoiceOver、系统材质及显示器适配仍须后续实机验证。
