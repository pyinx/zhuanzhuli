- 日期：2026-10-22
- 范围：[产品交互设计](产品交互设计.md)、[原型](../design/prototype/index.html)、视觉 token 与交互源码
- 方法：当前作者按 apple-design 技能复核，并查阅 Apple 官方 HIG；不是独立审查
- 阶段：本复核写于设计确认前；用户现已确认 v0.2 最新修订稿并登记 Gate 2。验证缺口仍保留，不进入应用开发

设计方向符合本产品的 macOS 定位：开始前清楚，工作时安静，需要时可控。本轮发现并修正了原型的具体偏差，但结论只覆盖设计说明与源码。尚无真实浏览器画面、交互操作或原生行为证据，因此不能宣布整体 UI／UX 已验收通过。

## 1. 苹果风格在这个产品中的含义

主窗口是一张清楚的开始表单，菜单栏提供少量相关控制，设置与历史按需打开。原生工作应用仍占据主要空间。这个组织方向保留，不增加持续占据桌面的大计时页。

控制面板应与菜单栏入口有清楚的空间关系，点击外部或按 Esc 可收起；打开设置或历史时先收起面板，避免层层叠加。这个取舍与 Apple 对 popover 的定位和关闭建议一致。[Apple HIG：Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers/)

材料服务层级与可读性：内容区采用稳定的背景，临时控制层可使用适当系统材质。正式应用跟随系统版本与辅助偏好，不将浏览器阴影或透明色当成原生材质，也不以满屏玻璃作为验收目标。[Apple HIG：Materials](https://developer.apple.com/design/human-interface-guidelines/materials)

动效只服务进入、理解和反馈。本产品没有已确认的拖拽、甩动或触摸手势需求，因此不为套用技能而引入弹簧库或手势流程。入场分镜是可跳过的媒体示意；工作背景静止，普通控件按下即时反馈，动作在释放时提交。[Apple HIG：Motion](https://developer.apple.com/design/human-interface-guidelines/motion)

## 2. 发现与处置

以下均为源码可确认的问题及修正，不将“已修正源码”写成“已实测通过”。

| 编号 | 优先级 | 发现及影响 | v0.2 修正 | 仍需证据 |
| --- | --- | --- | --- | --- |
| AD01 | P1 | 控制面板点击外部不收起，打开设置／历史时仍可能叠着面板，偏离临时控制的预期 | 外部点击收起；打开设置或历史先收起；Esc 优先关闭最近的控制层，再返回菜单入口 | 鼠标、键盘、窗口切换实测 |
| AD02 | P1 | 面板仅固定在右上角，入口宽度变化时空间对应不清楚 | 按菜单栏触发器位置计算锚点，限制边缘溢出，补充指向与展开语义 | 不同宽度、超时文字、放大后的定位截图；原生定位另测 |
| AD03 | P1 | 必要选择的背景已禁用，却没有匹配的视觉层级提示 | 必要提示增加背景暗层；日常控制保持非模态；背景禁用与提示显示同步 | 检查焦点、暗层范围与提示可读性；不能据此设计成覆盖其他真实应用的全局遮罩 |
| AD04 | P1 | 降低透明度和提高对比度未读取系统偏好，菜单栏等示意仍使用固定透明色 | 三项偏好分别读取与监听浏览器可暴露信号；评审工具可单独覆盖预览；透明层与边框有稳定回退 | 不同浏览器支持、实际 macOS 偏好、辅助技术组合 |
| AD05 | P1 | 字号、共享间距和窗口宽度全为固定像素，较大文字容易挤压控件 | 共享 token 改用相对单位，保持默认视觉尺度；表单可换行，窗口内容可滚动；中文标题去掉不必要的紧缩字距 | 100／150／200% 文字与缩放、最小窗口、长目标截图；网页缩放不证明原生文本适配 |
| AD06 | P1 | 工作窗口示意固定浅色背景，却继承深色辅助文字；场景小字直接叠在图片上，对比不可预测 | 工作内容统一使用语义外观；场景标题使用受控实底；辅助文字颜色修正 | 图片与材质合成、系统强调色、焦点环仍需实际对比度检查 |
| AD07 | P1 | 逐条删除覆盖上一条撤销，连续误删失去恢复路径 | 保留本页内的删除顺序并逐次撤销；以相邻记录身份恢复位置，避免新记录加入后错位；撤销后定位恢复的记录 | 连续删除、期间新增记录、撤销后焦点的真实操作；生产持久化未实现 |
| AD08 | P2 | 保护检查用固定 700ms 等待后自动显示就绪，容易把演示节奏误读成系统能力 | 去掉人工等待；明确说明未执行检查，由评审者手动切换“显示就绪状态（演示）” | 正式加载、取消、失败与耗时须由真实系统检查决定 |
| AD09 | P2 | 设置即时生效却额外要求“完成”；删除使用退格字符；其他应用示意存在无作用的关闭按钮 | 设置通过窗口关闭或 Esc 返回；删除改为垃圾桶示意符号并保留可访问名称；其他应用交通灯只做装饰 | 原生设置窗口、系统符号、完整键盘访问与 VoiceOver |
| AD10 | P2 | 首次配置也显示虚构“继续上次”；空历史在专注中仍称“开始一次” | 首次无记录不显示复用；日常复用来自本页上一条记录；运行中空历史显示“返回本次专注” | 首次与日常流程文案、数据边界检查 |

## 3. 排版、外观与反馈规则

系统字体、字级、字重和行距共同表达层级；计时数字使用等宽数字特性。中文小字号不额外增加装饰性字距。原型相对单位支持浏览器文字设置；真实 macOS 仍应使用系统文本样式与平台适配，不能把网页 rem 等同于原生 Dynamic Type。[Apple HIG：Typography](https://developer.apple.com/design/human-interface-guidelines/typography)

普通点击保留即时按下反馈，原型不在 pointer-down 执行业务动作；用户仍可在释放前取消点击。滑杆持续更新同一音量状态，设置面板与会话面板不各自保存副本。到点只提示一次，不切走工作焦点；没有新增声音、触觉或周期催促。

三项辅助偏好独立处理。初次读取可用的系统信号，未手动覆盖时跟随变化；评审工具的覆盖仅在本页有效，刷新恢复跟随。减少动态效果时取消位移与缩放；若用户开启人声，可保留静态引导。降低透明度时临时控制和菜单栏回到实底；提高对比度时强化边界并采用稳定表面。[Apple HIG：Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)

候选 token 仍由 design/prototype/tokens.css 唯一拥有。此次没有锁定最低系统版本、最终字体点数、系统材质类型或弹簧参数；正式控件与交通灯仍由 macOS 负责。

## 5. 可视评审时优先检查

| 路径 | 预期结果 |
| --- | --- |
| 专注中 → 菜单栏 → 外部点击／Esc | 入口与面板对应；面板收起，会话不结束；键盘关闭可回到入口 |
| 控制面板 → 设置／记录 | 不在面板上继续堆窗口；返回入口始终可达 |
| 受限／未验证 → 配置 → 检查演示 → 取消／手动结果 | 提示身份明确；取消不丢目标；不会经过固定等待自行宣称检查通过 |
| 深色 → 设置 → 专注工作说明 | 内容与辅助文字同一语义外观，无固定浅色底与深色文字变量混用 |
| 三项辅助偏好分别开启及组合开启 | 保留清楚反馈、稳定表面和可辨边界；静态人声引导可跳过 |
| 大字与窄窗口 → 长目标／自定义／设置 | 文字可读，关键操作可见或可滚动到达，不覆盖标签 |
| 连删两条 → 连续撤销；期间退出保存一条新记录 | 原记录能恢复，新增记录仍排在正确位置，焦点可继续操作 |
| 中文输入法 → 确认候选 → 正式开始 | 确认候选不误开始，Esc 只作用当前产品层；宿主快捷键保持可用 |

这些是待执行清单，不是测试通过记录。浏览器安全策略尚未允许自动检查本地原型，不申请通过额外协议或其他浏览器取得同一结果。正式系统能力仍保留在原有待验证清单。
