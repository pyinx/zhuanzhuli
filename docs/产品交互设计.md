## 1. 核心设计判断

已确认采用轻量主窗口与菜单栏控制相结合的方式。用户开始前看见目标、时长和已保存环境，进入后大窗口收起，工作回到原生应用；需要查看或调整时，再主动打开轻量控制。自然场景保留在环境层，计时不会持续占据主要工作区域。

用户明确回复“确认当前最新版设计”，确认对象为 v0.2 验证修订稿及本稿参数、流程与交互规则。下文方案比较保留设计依据；已获批的产品范围和 AC1–AC9 不变。设计确认不等于验证通过，也不自动授权应用开发。

## 2. 两个实际可选方案

| 对比 | A：轻量主窗口＋菜单栏控制（推荐） | B：仅菜单栏驻留＋弹出面板 |
| --- | --- | --- |
| 开始 | 独立窗口容纳目标、时长和环境概览 | 从菜单栏打开较小面板开始 |
| 工作 | 主窗口收起，用菜单栏轻量控制；可从窗口入口返回 | 无主要窗口，主要依赖菜单栏 |
| 首次设置 | 空间充分，系统配置与失败说明容易组织 | 需要多次跳出面板，窗口归属容易混淆 |
| 查找入口 | 可提供 Dock／窗口和菜单栏两条路径 | 菜单栏隐藏、拥挤或全屏时可达性更难保证 |
| 干扰 | 工作时收起即可；多一个窗口入口需要清楚语义 | 视觉占用更少，但发现成本更高 |
| 实现与验证代价 | 需统一主窗口、设置窗口和会话状态，关闭窗口不结束会话 | 需解决入口消失、激活、设置与历史窗口的回退路径 |
| 本轮呈现 | 原型呈现 A，作为推荐方案供评审 | 保留为真实替代方案，不标为已被用户否决 |

不采用始终置顶的大计时页或全屏仪表盘作为默认工作界面，因为它们持续占用工作空间，与既有产品目标不符。完整技术架构不在本轮比较范围。

| 项目 | 本稿参数 | 理由与调整成本 |
| --- | --- | --- |
| 首次预设时长 | 30 分钟 | 位于已确认预设中间；已随设计确认，试用效果仍待验证 |
| 自定义输入 | 1–180 的整数分钟 | 已确认的首版设计边界，试用效果仍待验证 |
| 入场时长 | 约 6 秒，可立即跳过 | 落在已确认约 5–10 秒范围内；原型只有分镜效果，不是最终视频 |
| 环境声音初始状态 | 候选为关闭，用户主动开启 | 避免突然发声；滑杆的初始位置只用于演示，正式音量需结合最终资源验证 |
| 有效计时开始 | 保护检查完成、入场结束或跳过后 | 准备过程不当作工作投入；已随最新版设计确认 |
| 入场中取消 | 回到保留目标和配置的开始窗口，不产生有效投入记录 | 避免把准备阶段当作专注记录 |
| 删除记录 | 单条删除后提供窗口内撤销，连续删除可逐次撤销 | 动作可恢复，避免每次弹确认；真实数据删除边界另行验证 |
| 关闭窗口 | 收起窗口，不等于退出专注 | 对应 Mac 窗口习惯，保留正在进行的工作；退出应用另有清理责任 |

## 5. 会话流程与行为契约

### 5.1 状态转移

准备 → 检查目标、时长与应用组合 → 检查保护 → 入场 → 专注 → 到点继续。

专注或超时 → 暂停 → 主动恢复到原计时阶段；专注、超时或暂停 → 退出并静默保存 → 准备。

保护未完整建立 → 完成配置／明确选择部分保护继续／取消。配置未完成时不自动跳到“已全面保护”。

异常恢复 → 保留可信时长的暂停状态 → 用户查看后主动继续或结束。锁屏、合盖、睡眠的真实事件接入仍待技术验证，原型用暂停状态解释结果。

| 当前状态 | 触发 | 下一状态与保留内容 | 用户看见什么 |
| --- | --- | --- | --- |
| 准备 | 目标为空／时长非法／应用为空 | 留在准备，保留已填内容 | 字段旁说明，焦点定位相关输入或选择入口 |
| 准备 | 开始，保护不完整 | 等待明确选择 | 配置、以部分保护继续、取消 |
| 等待保护 | 取消或 Esc | 回到准备；不计时 | 原目标和配置仍在 |
| 准备／保护选择 | 满足条件，或明确部分继续 | 入场；创建本次快照，暂不计有效时间 | 可跳过分镜 |
| 入场 | 结束／跳过／减少动态效果 | 专注，开始有效计时 | 大窗口收起，原生应用示意与菜单栏入口 |
| 入场 | Esc 取消 | 准备，不留有效投入记录 | 原目标和配置仍在 |
| 专注 | 预设时间到 | 超时，保护和累计继续 | 菜单栏短暂出现“预设时间到”，不切走工作焦点；打开面板可查看超时 |
| 专注／超时 | 暂停或系统自动暂停事件 | 暂停，冻结可信累计时间 | 环境恢复的说明，继续与退出 |
| 暂停 | 主动继续，保护检查满足 | 延续原专注／超时，不重置目标 | 恢复轻量控制 |
| 专注／超时／暂停 | 退出专注 | 静默保存，回到准备 | 无总结弹窗，历史主动打开 |
| 异常中断 | 再次打开 | 恢复提示与暂停会话 | 可信时间、查看暂停的专注／结束 |
| 任意可关闭界面 | 关闭窗口／面板 | 仅收起界面，会话仍由统一状态持有 | 从菜单栏、窗口或 Dock 入口返回 |

### 5.2 入场分镜与四主题

候选入场共约 6 秒：0–1 秒呈现场景和小人；1–4 秒小人走向环境深处，画面逐渐稳定；4–6 秒留出安静停顿，然后回到原生工作应用。跳过始终可达。减少动态效果时跳过动态分镜，直接进入静态环境；若用户开启人声，可保留静态、可跳过的引导。浏览器原型只用位移示意这一节奏，不代表最终镜头或 3D 动作已制作。

| 主题 | 方向画面 | 入场动作 | 工作时的克制 |
| --- | --- | --- | --- |
| 森林 | 林间光线、步道、层次清楚的树木 | 沿小路进入树影 | 静态低细节留白，相关应用保持清晰 |
| 沙滩 | 水平线、浅色沙面、缓慢潮汐的意象 | 从沙面走向海边 | 无持续大幅海浪动画 |
| 雪地 | 山脊、松树、开阔雪面 | 沿雪路走入安静处 | 控制亮度，无持续飘雪干扰 |
| 草原 | 柔和山丘、远树、天空留白 | 向远处山丘前行 | 静态背景，无持续摇摆与粒子 |

画面、环境声音与人声分别控制。关闭画面后沿用原桌面、不播放动态分镜；用户仍可独立开启声音或静态人声引导。人声仅在入场且默认关闭；环境声音关闭后音量控件保留位置并禁用。暂停停止声音，恢复是否接续音轨及真实淡入淡出细节留待媒体与技术验证。到点文字提示候选保留约 6 秒，不弹系统通知、不抢焦点；是否使用短音及其默认状态待真实通知保护方案验证后评审，原型不播放声音。

### 5.3 操作契约

| 操作 | 前提与结果 | 边界与失败 |
| --- | --- | --- |
| 开始 | 一句有效目标、合法时长、至少一个应用；检查后进入入场 | 空目标就地说明；非法时长保留输入；无应用引导选择；进入后不重复创建会话 |
| 复用目标 | 将上次目标放回输入框，可继续修改 | 示例数据有明确身份，不从实际工作内容读取 |
| 跳过入场 | 立即进入专注，开始有效计时 | 不跳过尚未处理的保护状态选择 |
| 暂停 | 停止有效计时和环境声音，恢复本次改变的工作环境 | 目标与剩余时间保留；不是休息阶段 |
| 恢复 | 延续同一会话；原本已超时则继续超时 | 若保护不完整需重新明确选择；不自动算入暂停间隔 |
| 到点 | 反馈一次，继续累计，不切走工作内容 | 不撤保护，不强制续时，不反复提示；音频反馈在本原型中不播放 |
| 访问范围外应用 | 提供三个明确选择 | 加入只影响本次，不自动改变默认组合；不强退对方应用 |
| 退出专注 | 保存本次事实，清理环境，回到准备 | 不弹总结，不推断目标完成，也不自动开下一段 |
| 关闭面板或窗口 | 收起相应界面，会话不随之丢失 | 保留返回入口；Esc 只关闭最近层或取消进入，不直接结束已开始会话 |
| 退出应用 | 应用层需结束会话并清理自己建立的环境 | 浏览器原型不拦截宿主的 ⌘Q、⌘W；真实系统快捷键不由网页冒充实现 |
| 删除与撤销 | 从历史清单移除单条记录，提供就地撤销 | 本原型只改本页内存示例；真实磁盘删除待后续实现验证 |

控制面板点击外部或按 Esc 收起，打开设置或历史时先收起面板。设置按当前界面说明即时更新，关闭窗口或 Esc 返回，不额外要求“完成”。必要选择显示匹配的背景层级提示；网页中的暗层仅用于本原型的上下文说明，不代表正式应用会覆盖所有真实工作应用。

保护检查过程由评审者手动切换结果，不设置人工延时后自动“就绪”；真实产品的等待、取消和失败必须由实际检查结果决定。首次无历史不显示“继续上次”，日常复用以本页最近记录为来源。

### 5.4 界面状态与数据归属

| 对象 | 设计层契约 | 归属与兼容性 |
| --- | --- | --- |
| 偏好 | 默认应用集合、场景、背景声音、音量、人声引导 | 开始前修改作为下次偏好；本原型仅内存，重载重置 |
| 会话 | 目标快照、预设时长、本次应用集合、已累计有效时间、运行或暂停 | 同一会话只有一个计时归属；打开多少窗口都不重复计时 |
| 保护状态 | 未配置、未验证、就绪、受限与用户明确接受的部分保护 | 独立于计时阶段；开始计时不证明保护生效 |
| 可见窗口 | 开始、轻量控制、设置、历史及必要确认／恢复提示 | 只控制呈现，不决定会话是否存在 |
| 历史记录 | 日期、目标、投入时长、会话事实状态 | 无完成分数；异常只记录可信部分 |

以上是交互契约，不是正式 API、数据库 schema 或迁移方案。当前没有已发布数据或服务接口需要迁移；后续技术设计须保留这些行为约束，不能把演示对象直接当作生产数据结构。

## 6. 视觉系统与组件

视觉方向是温和、清晰的 Mac 工具窗口。主要操作使用系统语义强调色，自然绿色只服务森林等环境，不把品牌色强加给所有控件。开始窗口不使用数据大屏、营销式首屏或常驻侧栏；设置窗口因需要分组导航，可以使用窄侧栏。

候选基础 token 的唯一来源是 design/prototype/tokens.css。字体采用系统字体栈；默认字号下正文约为 13–14 CSS 像素的设计参考尺寸，采用相对单位随用户文字设置缩放，不能将它等同于原生点数。标题用于定位，计时在主动打开的面板中突出。共享字级、间距、语义色、控件与窗口示意圆角集中管理；桌面说明图及插画的局部几何位于对应样式与 SVG。正式原生窗口的圆角与阴影由系统负责，网页尺寸不是原生控件规范。

工作说明图与辅助界面跟随语义外观，场景小字使用受控实底。系统可暴露的三项辅助偏好分别读取与监听；评审工具手动覆盖只在本页生效，刷新恢复跟随。此为设计路径和源码处理，不证明真实 macOS 偏好或无障碍通过。

| 组件 | 用途 | 状态与注意点 |
| --- | --- | --- |
| 目标输入 | 一句意图与复用 | 空、错误、长文字、中文组合输入；保留复制粘贴 |
| 时长分段选择 | 15／30／60 与自定义 | 单选、键盘可达；自定义错误就地展示 |
| 应用选择行 | 应用图标、名称、勾选 | 默认与本次范围文字不同；选中状态可读 |
| 场景预览 | 环境提示与主题切换 | 四主题一致，资源失败可恢复；全部为原创方向插画 |
| 声音控制 | 开关、独立音量、人声选项 | 默认人声关闭；状态与音量分开；原型不播放音频 |
| 轻量会话面板 | 目标、计时、保护、暂停与退出 | 普通、超时、暂停、部分保护；不常驻占据工作 |
| 保护提示 | 配置、部分继续、取消 | 演示身份明确，不用未知状态冒充全部生效 |
| 历史列表 | 日期分组与事实记录 | 空、正常、异常、单条删除与撤销 |

这些都是新设计组件或其状态变体，没有可复用的既有产品组件。它们是原型资产，未登记为真实原生实现。

## 7. 原生体验映射
