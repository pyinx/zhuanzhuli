原型可直接在浏览器中手动打开，不需要构建、安装依赖或网络。顶部工具条属于评审工具，可选择正常、超时、暂停、部分保护、历史、异常恢复、长目标等状态，并切换外观和辅助偏好模拟。

切换评审状态会重建示例应用组合、计时与记录；刷新也会重置。本页从不生成真实专注记录。

## 可操作路径

1. 在目标框输入一句话，或点击复用上次目标。
2. 选择 15／30／60 分钟，或输入候选范围 1–180 的整数分钟。
3. 在“更改…”中选择应用，在“场景设置…”中选择四主题或关闭画面；声音与人声独立控制。
4. 点击开始，查看约 6 秒的入场分镜，或立即跳过。
5. 工作区只保留原生应用说明图，通过右上菜单栏计时打开控制面板。
6. 暂停、恢复或退出。退出不弹总结，示例记录可在“记录”主动查看。
7. 顶部“保护受限”可查看配置、部分保护继续、取消的选择；“异常恢复”先保留在暂停状态。

## 证据边界

本原型只在本页内存中模拟计时与记录，重载即重置。不读取工作内容，不改变系统设置，不操作其他应用，不播放音频。窗口控件、背景、材质和图标是明确标识的设计示意，不能证明原生 API、系统权限或 VoiceOver 已生效。

自动浏览器因 file 协议安全策略拒绝读取本页，尚未完成真实浏览器交互和截图验证。没有通过其他浏览器、协议转换或间接执行绕过该限制。本地语法、资源和资料结构检查不替代可视验收。

## 静态校验

在项目根目录运行 `python3 design/validate.py`。它检查源文件、资源、本地链接存在性和原始需求哈希，计算浅深色固定回退色的实底文字对比度，并调用 `node --check`；不启动浏览器。对比度结果不包括图片、透明合成或系统强调色。需要本地 Python 3 与 Node。此命令不证明画面、交互、VoiceOver 或原生能力正确。

v0.2 补充：控制面板外部点击／Esc 收起，打开设置或历史先收起面板；设置即时更新，用关闭窗口或 Esc 返回。保护检查演示需手动选择结果，不会经过固定等待自动“就绪”。连续删除可依次撤销。辅助偏好初次跟随系统可用信号，评审工具覆盖仅在本页有效。

本轮验证修订补充入场键盘路径、错误及允许应用后的焦点、跨会话提示清理与恢复目标一致性；画布改为适应视口，各窗口内部滚动，入场文字采用受控底色。仍未取得浏览器操作或截图结果；刷新已打开的原型可手动检查最新稿。

可将该真实命令作为 harness 的 `test` 候选；当前尚未配置到人工拥有的命令表。`ui:shot` 仍需真实截图能力，不能用此校验替代。
