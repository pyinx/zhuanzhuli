## 动画参考顺序

每个主题采用相同编号：

1. `00-clean.png`：无人背景。可用于开场，也用于完全隐去后的终帧。
2. `01-distant.png`：人物在远处朝镜头走来。
3. `02-near.png`：人物走到近处。
4. `03-seated.png`：人物盘坐、闭眼，双手自然放在膝上。
5. `04-dissolve.png`：同一坐姿逐渐隐入环境的半透明视觉参考。
6. 回到 `00-clean.png`，留下安静风景。

场景文件均为不透明 RGB 图片；`04-dissolve` 的人物透明感已合成在完整场景中。可独立合成的透明素材是 `character/` 下的角色三视图。

## 制作边界与检查结果

- 24 张 PNG 均已完整解码；数量、预期文件集合、提示词覆盖、横竖比例与角色 alpha 通道检查通过。
- 角色三视图为 RGBA，包含完全透明背景与接近不透明的人物像素，保留内置工具原始透明通道。
- 场景按 3024:1964 的 Mac 屏幕比例构图，原生输出约为 1.5K 宽。它们不是 3024×1964 或 4K 图片，未使用插值放大伪装成更高分辨率。
- 各关键帧是独立生成的静态图片。整体镜头、人物与景物关系保持接近，细节并非逐像素锁定；森林、草原和雪地存在 1–2 像素的画布尺寸差异。视频制作时需要统一画布，并视具体工具进行背景对齐或以无人背景作为固定底图。
- 图标 PNG 保留为设计母图；2026-10-27 已由 `scripts/build.py` 在构建时生成十种 16–1024 像素表示的 `AppIcon.icns`，通过 `CFBundleIconFile` 接入应用。`scripts/verify.py package` 验证图标声明、解包尺寸与签名。动画和场景资源接入仍按各自变更推进；现有 `assets/media/` 未被本次图标接入替换。
- 已运行 `hx check 2026-10-24-focus-native-experience`。它仍提示原生 UI 变更的应用验收证据过期和独立审查缺失；这些应用验收未在本次仅生成图片的任务中重跑，不将图片交付视为应用验收通过。
